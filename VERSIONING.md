# Versioning

## Policy

AIP Enterprise uses Semantic Versioning.

- `MAJOR`: breaking changes
- `MINOR`: new features without breaking compatibility
- `PATCH`: bug fixes and maintenance

## Current Version

- `0.1.0`

## Release Workflow

1. Update the version in `pyproject.toml`.
2. Update `CHANGELOG.md`.
3. Create a release branch.
4. Tag the release as `vX.Y.Z`.
5. Publish artifacts.
